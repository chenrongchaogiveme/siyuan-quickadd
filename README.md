# QuickAdd for SiYuan

类似 [Obsidian QuickAdd](https://github.com/chhoumann/quickadd) 的思源笔记插件,：把「记录想法」「新建笔记」「一串组合操作」变成一次点击 / 一个快捷键。

> 当前版本：`1.0.0`，适配思源 3.8.9，零构建,更低版本的思源没有经过测试（直接运行 `index.js`）。

## 功能

| 类型 | 作用 |
| --- | --- |
| **记录（capture）** | 把一段 Markdown 追加/插入到当前文档、指定路径文档、今天的日记，或光标处 |
| **新建文档（template）** | 用内联模板 / 思源模板文件，按标题与路径规则新建文档；位置支持「指定笔记本 + 父路径 / 当前文档所在目录 / 当前文档的子文档 / 当前笔记本根目录」 |
| **宏（macro）** | 按顺序执行多个动作，变量只填写一次 |
| **选择动作（multi）** | 支持单选入口，或勾选多个动作后按配置顺序批量执行 |

触发方式：

- 顶栏 ⚡ 按钮打开搜索面板（`↑` `↓` 选择，`Enter` 执行，`Esc` 关闭）
- 命令面板（`Ctrl+P`）搜索 `QuickAdd: 执行：动作名`
- 编辑器输入 `/` 后选择动作
- 默认触发插件面板快捷键 `Ctrl+Alt+Q`
- 在动作里填写快捷键（如 `Ctrl+Alt+1`），全局生效

## 安装

插件目录：`<工作空间>/data/plugins/siyuan-quickadd`。

1. 把本文件夹完整复制到 `data/plugins/siyuan-quickadd`；
2. 在 `data/storage/petal/petals.json` 中加入（或修改）一条记录：

```json
{
  "name": "siyuan-quickadd",
  "displayName": "QuickAdd 快速添加",
  "version": "1.0.0",
  "enabled": true,
  "incompatible": false,
  "disabledInPublish": false,
  "userDisabledInPublish": false,
  "disallowInstall": false,
  "js": "",
  "css": "",
  "i18n": null,
  "kernel": {"js": "", "existed": false, "incompatible": true}
}
```

3. 重启思源，或执行一次 `设置 → 集市 → 插件` 的刷新。

## 快速开始

安装后顶栏会出现 ⚡，点击后有两个示例动作：

- **快速记录**：把 `- HH:mm 内容` 追加到当前文档末尾；
- **新建笔记**：在 `/ `下按「日期 + 标题」新建文档。

在「管理动作」里可以新增、编辑、排序、启停、导入导出动作。



## 变量

在内容、标题、路径里都可以使用：

| 变量 | 说明 |
| --- | --- |
| `{{date}}` / `{{DATE}}` | `2026-11-08` |
| `{{date:YYYY年MM月DD日}}` | 自定义日期格式，支持 `YYYY YY MM M DD D HH H mm m ss s SSS ddd dddd`，`[文字]` 原样输出 |
| `{{time}}` / `{{TIME}}` | `09:30` |
| `{{datetime}}` | `2026-11-08 09:30` |
| `{{input:提示语}}` / `{{VALUE:提示语}}` | 执行前弹窗填写，同一提示语只填一次 |
| `{{input}}` / `{{VALUE}}` | 同上，提示语为「内容」 |
| `{{title}}` / `{{TITLE}}` | 当前文档标题；新建文档时为新文档标题 |
| `{{docId}}` `{{docPath}}` `{{notebook}}` | 当前文档信息 |
| `{{clipboard}}` / `{{CLIPBOARD}}` | 系统剪贴板 |
| `{{selection}}` | 当前选中的文字 |
| `{{random:6}}` | 6 位随机字符串 |
| `{{cursor}}` | 光标占位符（会被移除） |

## 记录动作的目标与位置

- **当前文档**：文末 / 文首 / 当前块之后 / 作为当前块子块
- **宏中新建/打开的文档**：在宏里接在“新建文档”步骤之后，动态指向该步骤创建或打开的文档，不需要提前填写文档 ID
- **光标处**：直接在编辑器中插入（保留撤销）
- **指定路径的文档**：填写文档 path（如 `/My/灵感`），不存在会自动创建
- **今天的日记**：调用思源自身的日记创建逻辑（遵循笔记本的日记设置）
- **指定文档 ID**：精确指定

## 模板动作

- **内联 Markdown**：直接写内容，支持上面的变量；
- **模板文件**：`data/templates` 下的文件，支持思源原生模板语法（`{{.title}}`、`{{.now | date "2006-01-02"}}`、Sprig 等），同时会先替换 QuickAdd 变量。

同名文档默认「打开已有文档」，也可以选择「仍然新建」。

宏中执行“新建文档”后，后续记录动作的目标可以选择「宏中新建/打开的文档」；如果新文档设置为执行后打开，宏内的“当前文档”上下文也会同步切换，因此原有的“当前文档”目标可以直接继续使用。

模板文件的路径可以从 `data/templates` 下拉选择，也可以点「刷新」重新读取；父路径可以点「选择」直接浏览所选笔记本里的文档（例如 `/技能学习/编程`），也可以手动输入，缺失的父文档会自动创建。

勾选「执行时先选择子路径」后，每次执行会先列出该父路径下已有的全部层级，例如 `技能学习/英语学习/语法练习`；选好保存位置后，再填写标题等变量。可以直接选中已有路径复用，也可以在输入框里写一个新名称；按 Enter 后会创建这个新层级，新文档放在所选路径下。

- 选择 `技能学习`：新文档直接成为「技能学习」的子文档；
- 选择 `技能学习/英语学习`：新文档添加到已有技能分类；
- 输入 `书法学习`：自动创建 `技能学习/书法学习`，再在其中新建文档。

思源 3.8.9 在一次性创建多级新父路径时，偶尔会返回 `document metadata is not ready`。插件现在会自动把这种情况拆成逐级创建：先建缺失的父分类并等待其元数据可用，再创建最终笔记；已有分类仍保持原来的单次创建速度。

位置模式的用途：

| 位置 | 适用场景 |
| --- | --- |
| 指定笔记本 + 父路径（绝对） | 跨笔记本归档，例如把学习笔记放到「技能学习 / 编程」 |
| 当前文档所在目录（同级） | 在当前目录快速新建一篇笔记 |
| 作为当前文档的子文档 | 往下拆子主题 |
| 当前笔记本根目录 | 收集箱式速记 |

## 选择动作（单选 / 多选）

选择动作是“运行时决定做什么”，宏是“配置时固定做什么”：

- **单选入口**：兼容旧版行为，弹窗后只执行一个子动作；
- **多选执行**：弹窗后可勾选多个子动作，按「包含的动作」列表顺序依次执行；
- **分组展示**：子动作按动作设置里的「分组」归类，未填写分组的动作放在最后；
- **共享上下文**：同一次多选中的新建文档、记录、宏等动作共用上下文，前一步创建或打开的文档可以被后一步继续使用；
- **失败策略**：默认某个动作失败后停止；关闭「出错时停止」后会继续执行，并在结束时汇总成功与失败数量。

多选每次至少选择一个动作；关闭弹窗或点击取消不会执行任何内容。选择动作不能再嵌套另一个选择动作。

## 开发

```powershell
node --check index.js
node --test tests/macro-inputs.test.cjs
```

`index.js` 只负责插件生命周期和模块装配，其余代码按职责拆分在 `src/`：

```text
index.js          插件入口、命令、设置、生命周期
src/
  host.js         思源宿主 API 注入
  utils.js        通用工具、日期格式化
  vars.js         QuickAdd 模板变量与 Go 模板兼容
  api.js          思源 API、路径和文档创建
  settings.js     默认配置与配置规范化
  context.js      编辑器上下文、目标文档解析
  actions.js      记录、模板、宏和动作执行
  ui.js           面板、填写、选择器和管理界面
  hotkeys.js      快捷键解析
```

## 已知限制

- 宏和多选执行内部不能嵌套「选择动作」；
- 模板文件模式依赖思源自身的模板渲染，`{{input}}` 等变量会先被本插件替换；
- 快捷键是插件自己监听的，不会出现在思源「快捷键」设置里，也不会与内置快捷键冲突检测；
- 仅为桌面端 / 浏览器桌面端做过交互设计，移动端可加载但未实测。
